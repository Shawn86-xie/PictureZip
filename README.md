# 图片批量压缩工具

一个基于Python的图形界面工具，用于批量压缩图片文件（JPG/PNG/WEBP）并保留目录结构，同时支持复制非图片文件。

## 功能特性

- **批量处理**：支持整个文件夹的图片批量压缩
- **智能压缩**：根据预设自动调整图片尺寸和质量
- **格式支持**：JPG、PNG、WEBP、BMP、TIFF、GIF 格式自动处理
- **EXIF 保留**：保留相机型号、拍摄参数、GPS 等元数据
- **目录保持**：保留原始文件夹结构，自动创建输出目录
- **增量处理**：只处理新增或修改过的文件，提高处理效率
- **非图片文件复制**：可选项复制非图片文件到目标目录
- **图形界面**：友好的GUI界面，支持拖放操作
- **进度显示**：实时显示处理进度和当前文件
- **详细报告**：生成CSV格式的处理报告，包含文件统计信息

## 安装依赖

### 系统要求
- Python 3.7 或更高版本
- Windows / macOS / Linux 均支持
  - macOS：需从 [python.org](https://www.python.org/downloads/macos/) 安装带 Tk 的版本，
    或使用 `brew install python-tk`
  - 拖放功能依赖 `tkinterdnd2`，各平台均可用

### 安装步骤

1. 克隆或下载本项目：
   ```bash
   git clone https://github.com/Shawn86-xie/PictureZip.git
   cd PictureZip
   ```

2. 安装Python依赖：
   ```bash
   pip install pillow tkinterdnd2
   ```
   
   或者使用requirements.txt：
   ```bash
   pip install -r requirements.txt
   ```

3. 如果需要拖放功能，确保安装`tkinterdnd2`：
   ```bash
   pip install tkinterdnd2
   ```

## 使用方法

### 运行程序

```bash
python compress_images.py
```

### 双击启动（macOS）

运行 `make_app.sh` 可生成一个标准的 macOS 应用 `PictureZip.app`，
之后在 Finder 里**双击即可启动**，不会弹出终端窗口：

```bash
./make_app.sh              # 在项目目录生成 PictureZip.app
./make_app.sh --install    # 同时复制到 ~/Applications
```

生成的应用带有自定义图标，菜单栏和 Dock 都显示为「图片批量压缩」。
`--install` 之后可以直接把它拖到 Dock 栏，或从启动台打开。

> 如果 `.app` 被移动到别处，启动器会依次尝试：环境变量 `PICTUREZIP_HOME` →
> 从当前位置向上查找项目目录 → 构建时记录的绝对路径。

### 界面操作说明

1. **选择输入/输出目录**：
   - 点击"选择..."按钮或直接拖放文件夹到输入框
   - **输出目录可以不选**：未选择时会在输入目录旁自动创建一个平行的
     `压缩_<目录名>` 文件夹，界面下方会显示实际输出位置
   - 若手动指定了输出目录，则以你指定的为准

2. **设置处理选项**：
   - ✅ 递归子文件夹：处理子目录中的文件
   - ✅ 处理图片（压缩/缩放）：启用图片压缩功能
   - ✅ 复制非图片文件：将其他类型文件复制到目标目录
   - ✅ 增量模式（只重处理已修改的文件）：只重做源文件比输出更新的文件，其余跳过
   - ☐ 强制覆盖（忽略增量，全部重做）：忽略增量判断，对所有文件重新处理
   - ✅ 压缩文件加"压缩_"前缀：被压缩的图片加前缀（`风景.jpg` → `压缩_风景.jpg`），
     仅复制的文件保持原名（`说明.txt` → `说明.txt`）。取消勾选则所有文件保持原名

3. **选择压缩预设**：
   - **PPT 最稳（推荐） 1600 + Q78**：适合PPT演示，平衡质量和大小
   - **更清晰（大厅屏/投影） 1920 + Q80**：适合大屏幕展示
   - **更小（文件很大/电脑较老） 1280 + Q75**：节省存储空间
   - **论文/高保真 3000 + Q88**：高质量需求
   - **自定义**：手动设置参数

4. **开始处理**：
   - 点击"开始"按钮启动批量处理
   - 点击"停止"按钮可中断处理
   - 处理完成后可点击"打开输出目录"查看结果

## 技术参数

### 压缩算法
- **尺寸调整**：保持宽高比，按最长边缩放（只缩不放）
- **JPG压缩**：使用PIL的优化和渐进式编码
- **PNG处理**：仅优化压缩，避免量化带来的色带问题
- **WEBP支持**：高质量WEBP编码，质量随预设联动
- **TIFF处理**：使用 deflate 无损压缩
- **GIF处理**：逐帧缩放，保留动画与帧时长
- **BMP处理**：BMP 格式本身无法压缩，自动转换为 JPG 输出
- **EXIF保留**：相机型号、拍摄参数、GPS 等元数据会保留到输出文件

### 支持格式与输出

| 输入格式 | 输出格式 | 说明 |
|---------|---------|------|
| JPG / JPEG | .jpg | |
| PNG | .png | |
| WEBP | .webp | |
| BMP | .jpg | BMP 无压缩能力，转为 JPEG |
| TIFF / TIF | .tif / .tiff | deflate 无损压缩 |
| GIF | .gif | 保留动画 |

> 若 BMP 转换后的文件名与已有文件冲突（如 `photo.bmp` 与 `photo.jpg` 同名），
> 转换结果会另存为 `photo_bmp.jpg`，两者互不覆盖。
>
> GIF 输出的 EXIF 会被丢弃（GIF 格式不支持 EXIF）。
> TIFF 输出会丢弃 GPS 子块（Pillow 无法写入），其余 EXIF 保留。

### 预设参数
| 预设名称 | 最长边(px) | JPG质量 | WEBP质量 | 适用场景 |
|---------|-----------|--------|---------|---------|
| PPT 最稳（推荐） | 1600 | 78 | 80 | 日常PPT、文档嵌入 |
| 更清晰（大厅屏/投影） | 1920 | 80 | 82 | 投影、大屏展示 |
| 更小（文件很大/电脑较老） | 1280 | 75 | 76 | 节省空间、老旧设备 |
| 论文/高保真 | 3000 | 88 | 88 | 印刷、高质量要求 |

## 输出结果

处理完成后会生成：
1. **压缩后的图片文件**：保留在原相对路径位置，文件名加"压缩_"前缀
2. **非图片文件**：按原样复制，**文件名保持原样**
3. **report.csv文件**：包含处理详细统计，位于输出目录根下

### 输出示例

输入目录 `照片集/`：

```
照片集/
├── 风景.jpg
├── 子目录/
│   ├── 人物.png
│   ├── 素材.bmp
│   └── 说明.txt
```

未选择输出目录时，自动生成平行文件夹 `压缩_照片集/`：

```
压缩_照片集/
├── 压缩_风景.jpg          ← 压缩了，加前缀
├── 子目录/
│   ├── 压缩_人物.png      ← 压缩了，加前缀
│   ├── 压缩_素材.jpg      ← 压缩了（BMP转JPG），加前缀
│   └── 说明.txt           ← 仅复制，保持原名
└── report.csv
```

### CSV报告字段
- `relative_path`: 源文件相对路径
- `output_path`: 输出文件相对路径（未生成时为空）
- `type`: 文件类型（image/other）
- `action`: 执行操作（compress/copy/skip/error）
- `input_bytes`: 输入文件大小（字节）
- `output_bytes`: 输出文件大小（字节）
- `message`: 处理消息（如 `new` / `refresh(源文件已更新)` / `skip(incremental: 已是最新)`）

## 增量模式与覆盖的组合

| 增量模式 | 强制覆盖 | 行为 |
|---------|---------|------|
| ✅ | ☐ | 只重做源文件比输出更新的文件；其余跳过 |
| ✅ | ✅ | 忽略增量，全部重新处理 |
| ☐ | ☐ | 已存在的输出文件一律跳过 |
| ☐ | ✅ | 忽略增量，全部重新处理 |

> 输出目录若位于输入目录内部，程序会自动排除该目录，避免输出文件被再次复制造成层层嵌套。
> 输出目录不能与输入目录相同。

## 注意事项

1. **备份原始文件**：处理前建议备份重要图片
2. **输出目录**：建议使用空目录，避免文件覆盖
3. **大文件处理**：处理大量或大尺寸图片时可能需要较长时间
4. **内存使用**：处理超大图片时注意系统内存
5. **格式转换**：JPG/JPEG文件会统一输出为.jpg格式

## 故障排除

### 常见问题

1. **拖放功能不可用**
   - 确保已安装`tkinterdnd2`：`pip install tkinterdnd2`
   - 重启程序

2. **PIL模块错误**
   - 重新安装Pillow：`pip install --upgrade pillow`

3. **处理速度慢**
   - 关闭其他占用资源的程序
   - 减少同时处理的图片数量（可分批次处理）

4. **输出文件过大**
   - 尝试使用更低的质量设置
   - 减少最长边像素值
